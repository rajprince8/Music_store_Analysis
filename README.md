🎵 Music Store Data Analysis (SQL Project)
📌 Project Overview

This project analyzes a digital music store database using SQL to extract meaningful business insights. The analysis focuses on customers, invoices, genres, artists, and sales performance to support data-driven decision-making.

The project is structured into Easy, Moderate, and Advanced SQL queries, showcasing strong command over joins, subqueries, CTEs, window functions, and aggregations.
